# MyRoof – CPE Roof Measuring

Residential roof measuring for CoMo Premium Exteriors.

- Draw roof planes over a drone photo or satellite view, tag lines, apply pitch, place vents and penetrations.
- Report: squares, waste table, LF by line type, items, scaled drawing.
- Exports an AccuLynx-ready measurement XML (EagleView export layout).
- Works offline once installed; jobs are saved on the device only.

Live app: https://misteranders0n.github.io/myroof/
